# mle-analiz-loyalnosti-polzovatelej
# Анализ удержания и лояльности пользователей Яндекс Афиши

## 📖 Описание проекта

**Бизнес-задача:** Команда маркетинга Яндекс Афиши хочет повысить уровень удержания клиентов. Для этого необходимо понять, какие пользователи с большей вероятностью возвращаются на платформу и делают повторные заказы. 

В рамках исследования под **лояльным (вернувшимся) пользователем** понимается клиент, совершивший 2 и более заказа. Выявление факторов, влияющих на этот переход, позволит маркетингу точно настраивать рекламу, быстро выявлять перспективных клиентов и оптимизировать бюджеты.

**Данные:** Выгрузка из базы данных содержит информацию о транзакциях (дата, время, выручка, количество билетов), профиле заказа (устройство, тип мероприятия, регион) и поведенческих метриках (количество дней с предыдущей покупки).

**План исследования:**
1. Предобработка данных (очистка, конвертация валют, приведение типов).
2. Исследовательский анализ (EDA) и поиск «точек входа».
3. Расчет Retention по сегментам и проверка продуктовых гипотез.
4. Корреляционный анализ (Phi_k) для выявления скрытых связей.
5. Формулировка выводов и рекомендаций.

## 🚀 Инструкция по запуску

Проект написан на Python с использованием ООП. Вся логика инкапсулирована в классе `DataProcessor` (`src/processing.py`), а управление процессом осуществляется через главный скрипт `main.py`.

### Подготовка окружения
Убедитесь, что у вас установлен Python 3.8+ и активировано виртуальное окружение. Установите необходимые зависимости:

pip install pandas sqlalchemy psycopg2-binary phik matplotlib seaborn python-dotenv

### Подготовка данных
Для конвертации валют проекту необходим файл `final_tickets_tenge_df.csv`.
1. Скачайте его по ссылке: https://code.s3.yandex.net/datasets/final_tickets_tenge_df.csv
2. Положите скачанный файл в папку `data/` в корне проекта. 
(Если папки `data/` нет — создайте её).

### Структура проекта

├── data/

│   └── final_tickets_tenge_df.csv   # Файл с курсами валют

├── src/

│   └── processing.py                # Класс DataProcessor

### Запуск

Запустите главный скрипт из корневой папки проекта одной командой:

python3 main.py

### Итоги анализа и бизнес-выводы
В ходе анализа данных за период с 1 июня по 31 октября 2024 года (более 290 000 заказов) были получены следующие результаты:

Точки входа: 83% клиентов совершают первую покупку с мобильных устройств, а самая популярная категория — концерты (44%).

Портрет лояльного клиента: Пользователи десктопов возвращаются чуть чаще мобильных (64% против 61%). Начавшие с концертов возвращаются чаще (62%), чем пришедшие на спорт (55%).

География: Крупнейшие регионы (Топ-10) демонстрируют долю возврата 62.5%, тогда как менее активные — 58.4%. Размер региона имеет заметную связь с удержанием.

Время: День недели первой покупки не оказывает значимого влияния на возврат (разброс долей всего 4%).

Корреляция (Phi_k): Сильнее всего с числом заказов связаны средний интервал между покупками (0.428) и средняя выручка (0.281). Признаки первого заказа (устройство, тип, день недели) имеют крайне слабую связь (< 0.05).

### Бизнес-рекомендации для команды маркетинга:
Стимулировать вторую покупку. Около 39% пользователей уходят после первого заказа. Необходимо использовать персонализированные промокоды и push-рассылки сразу после первой транзакции.

Развивать мобильный канал. Учитывая доминирование смартфонов (83%), приоритетом должно стать улучшение мобильного UX и скорости загрузки.

Усилить работу в регионах-лидерах. Каменевский регион и Североярская область дают половину аудитории и показывают высокую возвращаемость. Там стоит запускать локальные кампании и партнерства.

Использовать поведенческие метрики. Поскольку интервал между покупками — сильнейший предиктор, нужно отслеживать «привычный ритм» клиента и отправлять триггерные предложения при его нарушении.

Отказаться от таргетинга по дням недели. День недели первой покупки не влияет на удержание, перераспределение рекламных бюджетов по дням не даст прироста конверсии.

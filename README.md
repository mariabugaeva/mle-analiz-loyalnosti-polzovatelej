# mle-analiz-loyalnosti-polzovatelej
# Анализ удержания и лояльности пользователей Яндекс Афиши

## 📖 Описание проекта

**Бизнес-задача:** Команда маркетинга Яндекс Афиши хочет повысить уровень удержания клиентов. Для этого необходимо понять, какие пользователи с большей вероятностью возвращаются на платформу и делают повторные заказы. 

В рамках исследования под **лояльным (вернувшимся) пользователем** понимается клиент, совершивший 2 и более заказа. Выявление факторов, влияющих на этот переход, позволит маркетингу точно настраивать рекламу, быстро выявлять перспективных клиентов и оптимизировать бюджеты.

**Данные:** Выгрузка из базы данных содержит информацию о транзакциях (дата, время, выручка, количество билетов), профиле заказа (устройство, тип мероприятия, регион) и поведенческих метриках (количество дней с предыдущей покупки).

**План исследования:**
1. Предобработка данных (очистка, конвертация валют, приведение типов).
2. Исследовательский анализ (EDA) и поиск «точек входа».
3. Расчет Retention по сегментам и проверка продуктовых гипотез.
4. Корреляционный анализ (Phi_k) для выявления скрытых связей.
5. Формулировка выводов и рекомендаций.

## 🚀 Инструкция по запуску

Проект написан на Python с использованием ООП. Вся логика инкапсулирована в классе `DataProcessor` (`src/processing.py`), а управление процессом осуществляется через главный скрипт `main.py`.

### Подготовка окружения
Убедитесь, что у вас установлен Python 3.8+ и активировано виртуальное окружение. Установите необходимые зависимости:

pip install pandas sqlalchemy psycopg2-binary phik matplotlib seaborn python-dotenv

### Подготовка данных
Для конвертации валют проекту необходим файл `final_tickets_tenge_df.csv`.
1. Скачайте его по ссылке: https://code.s3.yandex.net/datasets/final_tickets_tenge_df.csv
2. Положите скачанный файл в папку `data/` в корне проекта. 
(Если папки `data/` нет — создайте её).

### Структура проекта

├── data/

│   └── final_tickets_tenge_df.csv   # Файл с курсами валют

├── src/

│   └── processing.py                # Класс DataProcessor

└── main.py                          # Главный скрипт запуска

### Запуск

Запустите главный скрипт из корневой папки проекта одной командой:

python3 main.py

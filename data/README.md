# Папка для датасетов

**Данные для проекта**

В этой папке должен находиться файл `final_tickets_tenge_df.csv` с курсами валют.

## Откуда скачать
Вы можете скачать его по официальной ссылке курса:
https://code.s3.yandex.net/datasets/final_tickets_tenge_df.csv

## Куда положить
Сохраните скачанный файл как `final_tickets_tenge_df.csv` в этой папке (`data/final_tickets_tenge_df.csv`).
